# Plugin Bar

![Plugin Bar](help/img/plugin-bar.png)

On the Plugin Bar you can check all plugins installed in your device. From there you can drag any plugin into your pedalboard in order to load it.
Plugins are divided into different categories in order to help you finding the plugin you need. 

**Check [this page](https://wiki.mod.audio/wiki/MOD_Web_GUI_User_Guide#Constructor) for more info**
