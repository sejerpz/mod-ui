# Manage CV Ports

![Manage CV Ports](help/img/manage-cv-ports.png)

By clicking on this button you activate the "Managing CV ports" mode of the WebGUI.
With this mode active and plugins that can output CV messages loaded in your pedalboard, you can check the CV output ports that you wish to use and label them, so later you can use these ports to assign on any parameter of your pedalboard via CV assignment.

**Check [this page](https://wiki.mod.audio/wiki/MOD_Web_GUI_User_Guide#Assigning_CV_to_Parameters) for more info on how to create a CV assignment**
