Outputs

Automatically copy the audio data from an unconnected output to another.
With this enabled, the 2 outputs will receive the same data if one of them is unconnected.
Takes effect after a reboot.

The Duo X S/PDIF outputs can be set to mirror the analog output or be treated independently.
Mirror mode is default, where S/PDIF will contain the same audio signal as the analog outputs.
Enable this option to have 2 extra outputs on your pedalboard.
Takes effect after a reboot.

Midi Controllers

If enabled, when a paramater has a midi binding and that parameter is change on the MOD, midi is sent out of the MOD to update the controller.

If midi feedback is enabled and this is enabled, bound midi messages are sent out from the MOD. This is a rare option and is only used to keep multiple midi controllers in sync. Only enable this if you know that there is no possibility of a midi loop, if in any doubt do not enable this!

Enables Midi NRPN support for controlling parameters. If this is enabled then the following CC mssages cannot be used: CC6, CC38, CC98 and CC99.

Backup & Restore

Backup and restore user data using a USB stick.
A backup always holds your pedalboards, banks, settings and plugin presets, plus the parts you tick below. The previous backup on the stick is kept until the new one is complete.
A restore replaces the pedalboards, banks, settings and presets on this MOD (and the ticked parts that the backup holds). Plugins and licences are only added, never removed. The data a restore replaces is kept aside on the MOD until the next restore.
The USB stick needs enough free space. A FAT32 stick holds at most 4 GB per part (plugins, user files): above that, leave the part out or, on a MOD Dwarf, use a stick formatted as exFAT.

Reflash controller

Reinstall the firmware for the controller board.
This option is here for support reasons; If the power to your device was cut while installing the controller firmware, your device may end up in a state where the controller is not fully functional.

While the reflashing is happening, please DO NOT DISCONNECT THE POWER to the device.
There is a RISK OF BRICKING THE DEVICE if the power is cut.

Control Chain Device Update

×

Your Control Chain device firmware is ready to be updated.

To begin, follow these steps:

  • Disconnect the device from the Control Chain/Ethernet port
  • Hold down the first footswitch on the Control Chain device
  • While the first footswitch is down, connect the device to the MOD unit via USB
  • Wait for the "update completed" message
  • Disconnect the device from the USB port
  • Connect it to the Control Chain/Ethernet port once again

Note: The update should only take a few seconds.
