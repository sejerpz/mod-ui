**Starless** is an unofficial custom firmware for the MOD Dwarf developed by ALABS. 

It extends the standard firmware with additional features, user interface enhancements, and experimental improvements that are not available in the official release. Starless is intended for users who want to access advanced functionality while contributing feedback on features that may eventually become part of the official platform.
