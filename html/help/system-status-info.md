# System Status


This icon shows you if your MOD device up to date or some MOD OS update is available.
Hover on top of it and a pop-up label will inform you about the current status of the MOD OS running in your device.

When the system is up-to-date, the icon will look like the following:
![System Status up-to-date](help/img/SystemStatusUpToDate.png)

When a MOD OS update is available for your device, the icon will look like the following:
![System Status outdated](help/img/SystemStatusOutdated.png)
